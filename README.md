# 🐦 Flappy Bird – Unity Recreation

A simple and engaging recreation of the classic **Flappy Bird** game, developed using **Unity**. This project focuses on core gameplay mechanics, physics-based movement, obstacle spawning, scoring, and game state management.

---

## 🎮 Game Overview

Flappy Bird is a 2D arcade-style game where the player controls a bird and must navigate it through a series of pipes by tapping to flap upward while avoiding collisions.

**Objective:**  
Survive as long as possible and score high by passing through obstacles.

---
